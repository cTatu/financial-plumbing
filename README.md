# Financial Plumbing — Macro Knowledgebase

A chronological knowledgebase of **295 macro-finance analyses** (April 2025 → June 2026) covering Treasury auctions, repo/SOFR liquidity, bond yields, inflation, the dollar, gold/silver debasement, trade deficits, and fiscal dominance.

Each entry distills one analysis into: thesis, timestamped claims with numbers, charts shown, data-vs-interpretation split, testable predictions, recurring-theme tracking, notable quotes, and follow-ups.

## Structure

```
├── README.md              — this file
├── 00_INDEX.md            — Theme × Video matrix (295 rows, 12 themes)
└── YYYY-MM-DD_<slug>.md   — 295 dated entries, oldest first
```

## Entry format

Every file follows the same 7-section template:

1. **Thesis** — the argument in 2-4 sentences
2. **Key Claims** — timestamped, numbered facts (`[MM:SS]`, with units)
3. **Charts** — what was shown on screen and key readings
4. **Data vs Take** — verifiable prints (4A) vs interpretation (4B) vs testable predictions (4C)
5. **Themes Tracker** — which of the 12 canonical themes appear, and how the view evolved (`NEW / REAFFIRMS / EXTENDS / REVISES` with backlinks)
6. **Quotes** — verbatim lines carrying standalone insight
7. **Follow-ups** — what to watch to confirm or refute

## How to use it

- **Start with `00_INDEX.md`** — the matrix shows which videos cover which themes. Find a theme column, scan for ✓, open that entry.
- **Trace a theme over time** — each entry's §5 links backward to earlier entries on the same theme, so you can follow (e.g.) the SOFR-stress narrative from first print through resolution.
- **Check predictions** — §4C lists testable forward claims with check conditions; §7 gives concrete follow-ups per video.
- **Verify anything** — every claim carries a `[MM:SS]` timestamp back to the source transcript.

## Provenance

Entries were built from timestamped transcripts with per-word timing and AI-described video frames (charts, articles, data slides) embedded at their timestamps. Numbers with units, auction results, and official prints are preserved verbatim from the source material; interpretation is explicitly separated from data in every file (§4A vs §4B).

One entry (`2025-05-24`, silent-depression data video) is a placeholder — its source media was truncated and unprocessable, so no claims could be verified.
